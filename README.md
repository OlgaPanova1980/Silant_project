# Дипломный проект: Силант

Проект представляет собой веб-приложение "Электронная сервисная книжка" для Чебоксарского завода силовых агрегатов (ЧЗСА). 

---

## Описание REST API (Задание со звездочкой)

В рамках задания со звёздочкой в приложении настроен Django REST Framework (DRF) для выдачи данных в формате JSON. 

Доступ к данным закрыт для гостей и разграничен по ролям в системе с помощью `IsAuthenticated` (клиент видит только свои записи, сервисная компания — свои, менеджер — все).

### Доступные ссылки (Endpoints):
* `/api/machines/` — Данные по машинам и их комплектации
* `/api/maintenances/` — Данные по техническому обслуживанию (ТО)
* `/api/complaints/` — Данные по рекламациям и простоям
